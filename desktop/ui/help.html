Pokeclicker Cloud 操作手册

游戏装在电脑里，断网也能玩本地进度。联网后，用现有游戏密码与 play.ggzz.fun 网页共用云存档。

桌面程序 1.0.7 · 游戏 0.10.27 · Windows x64 · 这份帮助已随程序安装，断网也能查看。

换设备前：旧设备点“同步后换设备” → 等到成功 → 关闭旧端 → 在新端检查并接续云档。关闭窗口只保存本地，不保证上传云端。

1. 第一次使用：先备份两边的进度

这个新客户端与从官网下载的原 PokéClicker 客户端使用不同的数据目录。第一次看不到原来的训练家，是正常现象；它不会自动读取或覆盖原客户端。

  1. 在桌面新建一个文件夹，取名“宝可梦存档备份”。
  2. 打开原官方客户端，在游戏里点 Start Menu → Save / Enter Code → Download Save，保留得到的 .txt。选档页也可通过卡片 ⋮ → Download (backup) 导出。
  3. 把文件复制进备份文件夹，文件名前加“官方客户端”和当天日期，保留结尾的 .txt；然后关闭原客户端。
  4. 按本机配置记录打开平时使用的游戏网页，展开“云存档”，点 导出本地备份，同样保存一份，文件名前加“网页”和日期。
  5. 核对训练家、地区、宝可梦和大致游戏时间，决定要接着玩哪一份。如果网页进度就是要用的，点 同步后换设备，等待成功，再关闭网页。

“在云端”不等于“比另一台电脑新”。两边都玩过时不会自动合并金币、背包和收获。不确定就先留备份，别盲点覆盖。

之后只选一条路线：云档更新走 第 3 节；官方客户端更新走 第 4 节。如果你已经有确认过的最新云档，官方客户端里是旧进度，直接恢复云档即可。

2. 登录现有云存档

  1. 让电脑联网，在游戏选档页或游戏中展开 云存档 面板。首次验证前，先不要勾选自动同步。
  2. 点 登录云存档。程序弹出独立密码窗口，原游戏窗口会保留。
  3. 输入你现在登录游戏网页使用的游戏专用密码，点密码窗口里的登录按钮。
  4. 登录成功后点密码窗口里的 返回游戏，主窗口会自动检查连接。也可再点 检查连接；确认连接成功，再下载或上传存档。

不用填域名、仓库、分支和 GitHub token，也不用重新设置 Cloudflare。这里填的是游戏专用密码，不是 GitHub 或 Cloudflare 账号密码。

桌面版、Chrome、Edge 分别登录。网页登录过不代表桌面也登录了。每次登录最多保持 7 天，程序加密保存有期限的会话，不保存明文游戏密码。

忘记密码时，不用重装或删除数据；按项目完整手册第十四节，在有 Cloudflare 管理权限的电脑上运行原来的 cloud:password 流程重设。改密后，所有设备用新密码重新登录，本地与云端存档保留。

3. 云档更新：下载到新客户端

适用：你已经在网页成功上传，或另一台使用本定制版的电脑刚刚同步成功；想在这台电脑接着玩。

  1. 确认旧设备已点 同步后换设备 并等待成功，随后关闭旧端。
  2. 在新客户端完成登录，点 检查连接。
  3. 在选档页的云存档面板，将 选择本地存档 设为 恢复云档时新建本地槽位，再点 下载云档到本机。
  4. 点 备份并恢复，等程序重新载入，在新卡片上核对训练家、游戏时间和版本。
  5. 点击恢复出来的训练家卡片，进入游戏，核对地区、宝可梦、背包等关键进度。

第一次不用先创建空档，也不用先上传。下载失败就先处理连接问题，别用空档覆盖已有云档。云档已经正确恢复后，不必再导入官方客户端里的旧进度。

4. 官方客户端更新：导入旧存档

适用：你最后是在官方客户端里玩的，那里有你想保留的新进度，云档反而比较旧。先完成双方备份，再走这里。

  1. 确认原官方客户端已经导出 .txt 并关闭。
  2. 在新客户端选档页点 Import Save，选中刚导出的 .txt。
  3. 点击导入后的卡片进入游戏，核对训练家和进度。如果报游戏版本过新，先保留文件并更新定制版，不要强行继续。
  4. 在云存档面板的 选择本地存档 下拉框，选中这份导入档。
  5. 点 上传 / 立即同步，按提示确认 关联此存档。
  6. 如果提示冲突，再比较双方。确认当前本地就是要保留的进度，才点 使用本地进度覆盖云端。
  7. 等到明确显示 云端已确认保存，再继续做下一节的往返验证。

“检查连接成功”“本地已保存”和“请求已经发出”都不等于云端保存成功。若提示稍后重试，按提示等待，不连续点击。

本程序外壳版本是 1.0.7，游戏版本是 0.10.27。存档载入检查依据游戏数据版本，定制玩法还需要网页和桌面一起更新；不要通过旧端写回新版任务数据、在线宝珠进度、Battle Frontier 本轮起始层数及自动挂机设置，也不能把更高游戏版本的档导入旧版后强行覆盖云端。

5. 核对一次往返，再开启自动同步

第一次亲自做一次“桌面 → 网页 → 桌面”，验证实际账号和两台设备。先关闭自动同步，一次只在一端游玩。

  1. 桌面端：正常玩一小会儿，记住可核对的进度，然后点 同步后换设备。等成功后关闭客户端。
  2. 网页端：用 Chrome 或 Edge 打开本机配置记录中的游戏网址。第一次使用的浏览器先登录、下载恢复云档；已关联的浏览器检查最新云档再进入。
  3. 核对进度一致，再玩一小会儿；网页点 同步后换设备，等成功后关闭网页。
  4. 回桌面端：打开本程序，检查云档，进入已关联的存档，确认刚才网页里的进度已经接上。
  5. 两个方向都核对成功后，按需勾选 每 10 分钟自动同步。每台设备分别设置。

以后每次换设备：同步后换设备 → 等成功 → 关闭旧端 → 新端检查云档。

自动同步不能保证窗口关闭时刚好上传；它也可能受网络、休眠和游戏内关闭自动保存影响。需要立即换电脑时，仍按上面的顺序手动确认。

6. 断网游玩与重新连接

只要本机已经有存档，断网也能打开客户端。游戏、主题和翻译已经在包内，不要求浏览器先缓存网站。首次安装、没有本地档时，需要先联网下载云档，或者导入已有 .txt。

  1. 断网时点已关联的存档，云档检查可能失败。确认这台电脑的本地进度就是要玩的，按提示点 继续本地游戏。
  2. 正常游玩，本地继续按原游戏规则自动保存；云端暂时没有这些新变化。
  3. 准备关闭时，可以先点 导出本地备份 留一份 .txt。正常关闭会先保存本地，但不保证上传。
  4. 网络恢复后，点 检查连接。如果登录过期，先点 登录云存档，输入当前游戏密码，再检查连接。
  5. 点 上传 / 立即同步，等云端确认。若提示确认的是较早快照、仍有新进度，按提示等待后再同步。

离线电脑上有新进度时，别同时在另一设备继续同一份云档。重新联网发现双方都变了，会暂停自动同步并让你选择一份，不会自动把两边收获相加。

最小化窗口可以继续本机运行；电脑休眠、关机或游戏关闭后不会继续实时战斗。下次打开按原游戏规则计算离线收益，云端只保管存档。

7. 冲突、登录过期与退出

遇到的情况处理方法
进度冲突先导出本地备份，必要时下载恢复备份包。想继续另一设备的最新档，选“使用这份云端进度”；确定本机进度要保留，才选“使用本地进度覆盖云端”。
登录过期点“登录云存档”，独立窗口登录成功后点“返回游戏”，再检查连接、手动同步。不用刷新、重装或清理数据。
云档来自更新版本先导出本地备份，安装包含相应游戏版本的新定制客户端。不要用旧版覆盖新档。
连接失败、限流保留本地档，按提示等待再试。不要连点，也不要仅因网络失败就重设密码或 token。
重复双击没有新窗口本程序只允许一个实例；切回已经打开的 Pokeclicker Cloud 窗口即可。
本地保存失败保留当前窗口和能导出的备份，处理磁盘或存储问题。不要删除应用数据目录来“修复”。

想退出登录：先同步成功或导出本地备份，再点“退出登录”，确认“保存本地并退出”。程序清除本机云会话、关闭自动同步，保留本地游戏；你仍可以离线玩。退出不上传云端、不删档，也不退出其他设备。

下次要同步时重新登录即可。出问题只需保留报错文字和操作步骤，不要把游戏密码、GitHub token、会话文件或完整存档公开发送。

8. 升级、备份、重装和卸载

本客户端采用手动安装新版本，不会从官方仓库自动覆盖云存档功能。网页更新不等于电脑里的游戏文件也更新了。

  1. 更新前先“同步后换设备”并等成功，再“导出本地备份”保留一份 .txt。
  2. 完全关闭本程序，双击新的定制安装包，按默认步骤安装；不用先卸载，更不要手工删除应用数据。
  3. 打开新版，核对进度，再检查连接；需要登录时仍用原游戏专用密码。
  4. ZIP 版把新压缩包完整解压到新文件夹后启动。不要在压缩包里面直接运行，不要只复制一个 EXE。

本地存档放在哪里

按 Win + R，粘贴下面一行，按回车，可查看本定制版数据目录：

%APPDATA%\PokeclickerCloud

不要删除其中的 Local Storage、IndexedDB 或整个目录。安装版与 ZIP 版在同一个 Windows 账户下使用这同一个目录；ZIP 版“免安装”不代表把程序文件夹复制到别的电脑就带走了存档。

日常备份优先用“导出本地备份”的 .txt。想额外备份整个数据目录时，先关闭客户端，再复制整个文件夹。加密登录会话不能代替另一台电脑上的重新登录；跨电脑优先使用云档或 .txt。

卸载与重装

卸载前先留 .txt 备份和成功的云同步回执，再从 Windows“设置 → 应用 → 已安装的应用”卸载 Pokeclicker Cloud。不要同时手工删除上面的数据目录；数据保留时，重装可继续使用。

个人定制安装包没有代码签名证书，Windows 可能显示未知发布者。只使用本次交付的可信文件；系统直接阻止运行时保留提示排查，不需要关闭整机安全防护。

还能用 Chrome 或原官方客户端吗

Chrome 可以正常访问网页版。原官方客户端也可继续使用，但它没有这里的云同步功能，需要通过普通 .txt 手动转档。两个客户端不会自动共享本地数据。以后主要用本定制客户端和自建网页，可以减少手工传文件。

9. 自用玩法：培养、孵化、列表与助手设置

  1. 使用包含自用玩法功能的新版客户端；先点 云存档 → 导出本地备份，保留一份 .txt。
  2. 进入训练家存档，点 Start Menu → Settings → Gameplay，找到上方的 自用玩法。
  3. 把 地牢助手寻路 选为 优化寻路。助手仍按原速度和能力行动，不会自动开始任务。
  4. 把 道具价格 选为 固定基础价（购买不涨价）。原来已经涨价的普通道具也恢复按基础价购买，单买、批量和 Max 一起生效。
  5. 地牢助手服务费 默认已是 原价的 1%（门票原价）。可改为官方原价；助手仍被雇用时不能修改，等任务结束后再调整。
  6. 按原方法雇用助手，核对本批服务费、门票和总价再开始。三个选项跟随当前训练家的存档保存。

1% 是 0.1 折，不是 1 折。原服务费 10,000 金币变为 100 金币；每项原本为正的服务费最低收 1，门票原价。仍是整批预付，手动 Fire 通常不退余款，刷新不能恢复剩余任务。

寻路和价格默认采用官方模式，可以分别切回。固定价期间保留旧涨价倍率；关闭后恢复原倍率，不补扣或退款。按固定价买过维生素后，该存档不能再使用旧维生素退款码，切回官方价格也不会解除限制。

网页与所有电脑一起更新后再同步。先备份最新进度、确认上传并暂停旧端自动同步，再更新网页和全部 EXE，关闭旧网页标签和旧 EXE。用新版手动完成一次桌面与网页往返，核对选项和进度，再开自动同步。后台目前不会自动拦截同游戏版本的旧端，它可能丢掉新设置；打包 EXE 不会自动部署网页。

找不到“自用玩法”说明当前端仍是旧版。原官方客户端不保留这些设置，不要用它中转这份云档。运行中的助手任务和路径记忆不会跨设备恢复。

孵化槽位和外部宝可梦列表

在自用玩法中选择同时孵化槽位上限：4、8、12 或 16，默认 8。新增槽位仍在 Hatchery 中逐个购买，每槽价格为序号 × 500 任务点。调低上限不会丢弃已有蛋和进度，超出部分孵完后停止补蛋；已购买槽位保留，再调高无需重复购买。

外部 Pokémon List → Display Value 默认跟随排序，可单独选择显示的数据。展开 Filters 可搜索名称/编号，筛选属性、地区、分类、闪光、宝可病毒及形态。它与孵化 List 的筛选排序各自独立，修改外部列表不会改变自动补满孵化队列的规则。

Oak Items 经验调整

Magic Ball 从 5 升到 10 级合计需要 5 万次有效捕获。旧等级及已记录经验全部保留，达到新门槛后可逐级手动升级。Rocky Helmet 最高 30 级、6.50 倍，原 15 级可继续培养；15 到 30 级新增 3,000 万经验。两者后期每次升级仍固定收取 100 万金币。

任务按类型自动循环

完成 Tutorial Quests 后，每种已解锁任务类型各一条，自动接取、领奖并续接同类型。每行可独立刷新：每类每天首次免费，之后固定 100,000 金币；升级另给 1 次任意类型免费刷新，不叠加。自动续接始终免费，午夜和升级都保留当前进度。

原整批完成加成已计入单条任务，生成时固定；经验仍按基础奖励计算。旧档保留任务进度，已领取任务只补缺失加成，不重复发基础奖励。一次捕获或离线统计增量只结算当前任务，不连续刷完后续任务。

Dream Orbs 在线获取

解锁条件不变：获得 Tornadus、Thundurus 和 Landorus 后，每累计在线游戏 1 小时获得 1 个 Dream Orb，颜色从当前已解锁颜色中随机选择。宝珠窗口显示距离下一次产出的剩余时间。

最小化后游戏正常运行时也累计，断网本地游玩同样有效；关闭游戏、系统休眠或游戏停止运行的时间不累计。未满 1 小时的进度随存档保存并可跨端同步。旧档已有宝珠保留，新计时从零开始，不追补历史在线时间；其他离线收益规则不变。

Battle Frontier 快速挑战与主动结算

在 Battle Frontier 选择 Quick Challenge，默认从历史最高层数附近开始，保留最后 100 个已通关层再向上挑战。例如最高已完成 2,000 层，就从 1,901 层开始；如果较低层有已解锁但未领取的里程碑奖励，会提前从最早的待领取层开始。跳过层数不发经验、宝石、孵蛋进度，也不计入任务或累计通关数量。

Finish & Claim Rewards 结束本轮并领取已完整通关层数对应的 BP 和金币，清空检查点；无需等打输，暂停状态下也能领取。Pause & Save Progress 保留本轮进度但暂不领奖，下次点 Resume 继续。界面实时显示本轮已完成层数和可领取奖励。

快速挑战只结算本轮实际挑战区间。例如从 1,901 层开始并完成到 2,000 层，可领取 3,900 BP 和 390,000 金币。旧存档保留原结算规则；新版本保存本轮起始层数，暂停、重启和跨端同步后继续使用同一结算口径。请配套更新网页和桌面端，旧端会丢失这一新字段。

Battle Frontier 自动挂机

在 Auto Challenge 选择模式，点击 Start Auto Challenge / Resume Saved Run 开始；已有本轮进度时直接续打，不丢弃待领取奖励。默认 BP efficiency 每 5 秒根据当前队伍、属性克制和孵蛋输出变化重新估算刷取区间，比较继续推进与结算重开的 BP/分钟。输出下降会下调下一轮区间，恢复后允许提高；不改变孵化队列。较低层有已解锁但未领取的里程碑时会保留该层。

Fixed stage 打完指定层数自动领奖并循环；Record attempt 持续推进，打输后领奖并停止。循环领奖后等待 1 秒重开，不弹确认窗口；手动暂停或结算仍保留确认窗口并停止自动循环。Stop Automation (Keep Current Run) 只停止自动决策，正在进行的战斗继续，已有进度和收益保留。无安全刷取区间时暂停；连续 3 轮没有完整通关一层时停止，避免空转。

面板显示最近 5 层的实际 BP/分钟、下一轮预计区间、包含重开时间的预计循环收益及本次自动挂机已领取收益。预计区间是有界搜索的近似结果，结束层会动态变化，不保证全局最优。自动挂机只在游戏运行时执行；设置随存档保存，重启后需手动开启，不补发离线 BP。

维生素按标签筛选

打开 Vitamins → 标签 可选择一个或多个已有标签，与名称、地区和属性等条件组合筛选；选择“全部标签”清除标签限制。这里的筛选不改变孵化和外部列表。Remove ALL Vitamins (entire party) 仍会作用于整个队伍，范围不受筛选影响。
